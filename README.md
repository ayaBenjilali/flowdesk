# FlowDesk

Responsive web and mobile-friendly SaaS landing page for FlowDesk, built with Next.js, TypeScript, Tailwind CSS, Framer Motion, and Lucide icons.

## Live Website

View the site here:

https://flowdesk-brown.vercel.app/

## About

FlowDesk is a premium landing page concept for a workflow and productivity SaaS platform. It is designed for desktop and mobile browsers, with responsive sections, polished visuals, smooth motion, and clear conversion-focused content.

The page presents the product positioning, feature highlights, workflow benefits, social proof, pricing-style calls to action, and contact prompts in a modern web experience.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
